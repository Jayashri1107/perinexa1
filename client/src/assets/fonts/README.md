# Fonts

Bundled with the app so it works offline (Perinexa Brand & UI Guidelines v1.0, page 11), taken from the
Perinexa design system:

- **Jost** 400 / 500 / 600 – the interface.
- **Mukta** 400 / 600 – Hindi and Marathi (Devanagari) text and printouts.

Both are free fonts published on Google Fonts under the SIL Open Font License 1.1
(https://openfontlicense.org), which allows bundling them with software.

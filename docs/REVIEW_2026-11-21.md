## ABDM public callbacks

ABDM runs in **practice mode** (`ABDM_MODE` defaults to `practice`, `config.js:142`): every public callback answers 404,
so none of this can happen today. **A1, A2 and A3 must be closed before `ABDM_MODE` is sandbox or production.**
